# CarBall – 2D Unity Game Prototype

CarBall is a 2D top-down car football game prototype developed with Unity and C#. The project focuses on vehicle movement, physics-based interactions, and core football gameplay mechanics.

**Project Status:** Work in Progress

## Features

- Physics-based vehicle movement using Unity's Rigidbody2D
- Acceleration, reverse movement, and steering mechanics
- Drift mechanics
- Ball interaction and hitting mechanic
- Goal detection system
- Score tracking
- Ball and vehicle reset after a goal

## Controls

| Key | Action |
|---|---|
| W | Accelerate |
| S | Reverse |
| A | Turn Left |
| D | Turn Right |
| E | Hit the Ball |

## Technologies

- Unity
- C#
- Rigidbody2D
- Unity Input System

## Planned Features

- Local multiplayer (1v1)
- Single-player mode against AI
- Improved gameplay mechanics
- Additional game settings and UI improvements

## Project Status

This project is currently under development. Core vehicle movement, ball interaction, and scoring mechanics have been implemented. Multiplayer functionality and AI opponent behavior are planned for future development.
